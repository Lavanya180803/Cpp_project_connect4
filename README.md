# Cpp_project_connect4
This program implements the classic Connect 4 game using the C++ programming language. Connect 4 is a two-player strategy game in which players take turns dropping O or X into a vertical grid. The objective is to be the first player to form a horizontal, vertical, or diagonal line of four of one's own discs.
Key Features:
•	Two-player mode (Player 1 and Player 2)
•	6-row by 7-column grid (standard size)
•	Input validation to prevent invalid or full column entries
•	Win detection in all directions: horizontal, vertical, and both diagonals
•	Simple command-line interface for easy gameplay
•	This implementation uses a 2D array to represent the board and provides basic functions for board display, move insertion, and win checking.
